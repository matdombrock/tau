# FizzBuzzPop

Write a `solution.ts` exposing `generate()` that returns the FizzBuzzPop
output from 1 to N.

Rules: multiples of 3 → `Fizz`, 5 → `Buzz`, 7 → `Pop`, concatenated for
combinations, otherwise the number. The reference implementation lives in
`fizzbuzzpop.ts`; the verifier compares against it.
